# KeyHasher - C++ CLI Password Vault Simulation

A command-line credential manager simulation developed in C++. This project bridges university systems engineering coursework fundamentals with self-taught programming practice, focusing on data structures, input validation, and secure text handling concepts.

## [-] Core Features

- **Credential Ingestion:** Validates user-defined service names and enforces a strict minimum 8-character length constraint for passwords.
- **Vault Masking:** Dynamically obfuscates stored credentials, displaying masked text representations for secure visual auditing.
- **Service Search:** Implements a linear search algorithm with boolean flag tracking to locate specific stored records instantly.

## [>] Tech Stack

- **Language:** C++
- **Core Concepts:** Standard Vectors (`std::vector`), Control Flow (`while`, `for`, `if`), String Manipulation, Input Validation.

## [>] Background & Context

Developed as part of an ongoing portfolio initiative by a Systems Engineering undergraduate, merging formal academic computer science logic with independent self-taught systems programming practice.
